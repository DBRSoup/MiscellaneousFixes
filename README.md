# Miscellaneous Fixes

Miscellaneous fixes to both some bugs and calculations that are likely unintended. Full package deal for now!

## Current Issues Fixed
1. Voltaic Grenade's Live Wire did not work with Excited Plasma due to a wrong cast
2. Modular Construction uses an upgrade template that is not meant for it, causing infusions to severely nerf its stats more than stated
3. Cannonball uses a potency variable to lower visual effects and element application, but it is wrongly applied to damage as well
4. Oxythane's Promise rocket damage and explosion size are divided by the amount of projectiles while used with Three-In-One, causing the damage to be -90% instead of just -60%
